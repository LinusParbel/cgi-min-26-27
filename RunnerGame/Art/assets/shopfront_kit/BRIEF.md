# Essential shopfront kit

Original generic Hannover-inspired masonry architecture: warm sandstone shop, sandstone upper floor, and reddish brick upper floor. No specific building replica, logos, photographs or external texture sources.

Three independent modules; each bottom-centre origin (0,0,0), Blender Z up, front -Y. Export converts to Y up / -Z forward. Width 6m, total depth .8m, height 3.2m. Exact envelope x[-3,3], y[-.4,.4], z[0,3.2] includes ALL projections. Main wall front -.22m; cornice and discreet shallow awning project .18m to -.4m, never beyond the advertised footprint. Glass front -.06m is recessed .16m behind masonry. The awning is deliberately shallow for the fixed .8m footprint.

Shop glazing has central door, flanking display windows, frames, mullions and transoms. Upper windows have modeled reveals, frames, lintels and projecting sills. Continuous plinth/cornice and edge quoins finish all elevations. Each component box is closed; overlapping internal faces are retained. Opaque blue-grey glass uses no transparency or interior dependency.

Budget <=6000 combined triangles, shared 2048 atlas, one 32-sample bake. Editable Blender scene saved before bake. Build and verifier are separate; verifier fixes numerical contract independently from builder values. Presentation stack moves upper modules by +3.2 and +6.4m only in a preview manifest; individual exported modules remain ground-origin and reusable.
